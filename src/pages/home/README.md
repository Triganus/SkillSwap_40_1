# HomePage - Главная страница

## Описание

Полноценная главная страница приложения SkillSwap с поддержкой двух режимов
работы:

1. **Обычный режим** - отображение популярных, новых и рекомендуемых предложений
2. **Режим поиска** - отображение результатов поиска по параметру `?search=` в
   URL

## Реализованный функционал

### ✅ Обычный режим

В обычном режиме страница отображает три блока:

1. **Блок "Популярное"**
   - Отображает 3 карточки популярных предложений
   - Кнопка "Смотреть все" ведет на `/search?sort=popular`
   - Использует компонент `CardSectionUI`

2. **Блок "Новое"**
   - Отображает 3 карточки новых предложений
   - Кнопка "Смотреть все" ведет на `/search?sort=new`
   - Использует компонент `CardSectionUI`

3. **Блок "Рекомендуем"**
   - Бесконечный скролл с подгрузкой карточек
   - Автоматическая подгрузка при прокрутке до конца
   - Использует компонент `InfiniteGridUI`

### ✅ Режим поиска

При наличии параметра `?search=...` в URL:

- Отображается только блок с результатами поиска
- Заголовок показывает количество найденных предложений
- Используется `useSearchParams()` для чтения параметра из URL
- При изменении `searchQuery` автоматически диспатчится `setSearchQuery()` в
  Redux
- Режим определяется через: `const isSearching = searchQuery.trim().length > 0`

## Технические детали

### Используемые компоненты

- `CardSectionUI` - для блоков "Популярное" и "Новое"
- `InfiniteGridUI` - для блока "Рекомендуем" и результатов поиска
- `SkillCard` - карточка пользователя с навыками
- `TitleUI` - заголовки блоков

### Redux интеграция

Страница готова к интеграции с Redux store:

```typescript
// Используемые селекторы из skillsSlice
import {
  getPopularSkills,
  getNewSkills,
  getSearchResults,
  getSearchQuery,
  getSkillsLoading,
  setSearchQuery,
  filterSkills,
  fetchSkills,
} from '@entities/skill/model';
```

### Мок-данные

На данный момент используются мок-данные `MOCK_USERS_DATA` (15 пользователей с
навыками). После готовности `skillsSlice` нужно будет:

1. Раскомментировать `dispatch(fetchSkills())` в useEffect
2. Заменить мок-данные на данные из селекторов Redux
3. Адаптировать структуру данных под реальный API

## Адаптивность

### Мобильные устройства (< 768px)

- Карточки отображаются в одну колонку
- Кнопки "Смотреть все" занимают всю ширину
- Уменьшены отступы для экономии пространства
- Карточки растягиваются на всю доступную ширину

### Планшеты (768px - 1024px)

- Карточки отображаются в 2 колонки
- Оптимизированы отступы

### Desktop (> 1024px)

- Карточки отображаются в 3 колонки
- Максимальная ширина контейнера 1200px

## Навигация

### Внутренние ссылки

- `/search?sort=popular` - страница популярных предложений
- `/search?sort=new` - страница новых предложений
- `/?search=текст` - поиск по тексту

### Обработчики

- `onDetailsClick` - переход на страницу деталей пользователя (пока console.log)
- `onLikeClick` - добавление/удаление из избранного (пока console.log)
